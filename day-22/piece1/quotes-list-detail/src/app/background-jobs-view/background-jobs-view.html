Day 18: POST /api/jobs/quote-analysis/{quoteId} enqueues a ~5s "analysis" job onto a Channel-backed queue and returns 202 Accepted immediately - a BackgroundService (QueuedHostedService) drains the queue on its own loop, off the request thread.

Each job takes ~5 real seconds (chunked into 1s steps) - enough time to watch it move from Queued to Running to Completed below (this table polls every second). Stopping the API mid-job (Ctrl+C) cancels the in-flight job cleanly via its CancellationToken instead of the process dying mid-write - see the README for the graceful-shutdown log.
